01 / PROBLEM

記帳，本來就該很簡單。

01

記帳要開 App

手動打類別、換工具、整理匯總。不想為每筆花費開一個 App。

02

查資料要切 App

在 LINE 裡問，切到瀏覽器搜尋，看完再切回來。注意力被切成三段。

03

雲端 AI 有成本

逐字計費、需要 API key；敏感內容也不一定想送出門。

主要使用者：常用 LINE 的學生與小型團隊　·　設計目標：不離開聊天室、記帳免 API、累計即時
LINE Bot × Local LLM02
02 / SOLUTION

一個入口，兩種模式。

查 …

先搜尋，再讓本機模型整理；答案最後附來源。

新聞題走 Google News RSS；知識題走中文 Wikipedia。

查 玉山有多高 → 3,950 公尺＋Wikipedia 來源
咖啡 45 元

本地解析 merchant＋amount，分類後累計今日／本月。

記帳走本地解析＋加總，完全免 API；分類用關鍵字 heuristic。

咖啡 45 元 → 已記帳（飲食），今日累計…
Uber 60 → 已記帳（交通），累計更新
同一套 /ask 流程；展示頁不需要 LINE token。
LINE Bot × Local LLM03
03 / ENGINEERING

讓它能跑，而不是只看起來能跑。

01

非同步 202

Apps Script 先回 200，Flask 算完再直接呼叫 Reply API。

避免 LINE Webhook 逾時
02

先搜尋，再生成

Google News RSS＋Wikipedia，只把前 3 筆放進 prompt。

答案附來源，降低幻覺
03

2B＋暖機

gemma2:2b、num_predict=220；啟動時先 warm_up()。

暖機後約 5.9 秒
04

不把祕密寫進程式

本機用環境變數；Apps Script 用指令碼屬性。

交件前掃描 0 金鑰
