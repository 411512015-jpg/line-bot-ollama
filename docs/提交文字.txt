題目：LINE × 本地 AI 記帳小幫手

做什麼：在同一個 LINE 聊天視窗裡，「咖啡 45 元」這類格式會先被本地解析（merchant + amount + category），再回覆今日累計與本月累計；「查 …」則交給本機 Ollama 搜尋＋回答並附來源。

給誰用：手機不離身、常用 LINE 的學生與小型團隊；想玩本地 LLM、但不想付 API 費用的記帳者。

怎麼做：Google Apps Script 當 Webhook，Flask 轉接站跑在自己的電腦，ngrok 提供公開網址；記帳走本地解析，搜尋與模型推論都在本機。

怎麼測：11 個單元測試；展示頁實際輸入「咖啡 45 元」即時回累計；交件前用 scripts/check_submission.py 掃描金鑰與部署網址。

下一步：AI 做細分類、Flex Message、Webhook 簽章驗證、固定網域（Cloudflare Tunnel）。
